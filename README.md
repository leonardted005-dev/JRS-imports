# JRS Imports

A finished storefront for JRS Imports: curated handicrafts, fashion, and tech accessories from India, delivered across Namibia.

Prices are in Namibian dollars. Cart, account details, messages, and orders are stored in the browser. Checkout confirms an order without taking payment.

```bash
npm install
npm run dev
```

Open the local address Vite prints. `npm run build` writes a production bundle to `dist/`.
